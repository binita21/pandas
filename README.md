# Pandas Learning Notebook 

This repository contains my hands-on practice while learning the Pandas library for data analysis in Python. 
The notebook includes explanations, examples, and exercises covering the core concepts of Pandas.

## Topics Covered
- Introduction to Pandas
- Series and DataFrame
- Creating DataFrames
- Reading and Writing CSV files
- Data Inspection
  - `head()`
  - `tail()`
  - `describe()`
  - `info()`
  - `dtypes`
- Indexing and Selection
  - `loc`
  - `iloc`
- Selecting Rows and Columns
- Updating and Modifying Data
- Working with Indexes
- Basic Data Cleaning
- Statistical Functions
- NumPy with Pandas
- Practice Examples
- pandasbasics.ipynb -> consists basics concepts
- pandaspractice.ipynb -> consists the contents that i practiced.
